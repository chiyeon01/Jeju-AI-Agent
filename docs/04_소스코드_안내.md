## 2. Agent 실행 코드 (`backend/app/`)

| 파일 | 역할 |
|---|---|
| `main.py` | 앱 시작점. `/api/v1` 라우터·WebSocket 등록, 시작 시 허브 혼잡도 계산(백그라운드) |
| `services/profile_service.py` | **성향 분석 Agent** — 12문항 → 4축 점수 → 16유형, GPT 설명 |
| `services/course_service.py` | **코스 플래너 Agent** — 장소 점수화(성향·근거·평점·혼잡도·날씨·거리), 시간표, 다른 코스(GPT), 대화 수정(GPT) |
| `services/chat_service.py` | 코스 대화 해석 — GPT JSON(patch·prefs·reply), 실제로 바뀌는지 미리 계산, 규칙 기반 대체 |
| `services/course_session.py` | 사용자별 대화 선호(바다 보이는 카페, 장소 빼기 등) 기억 |
| `services/owner_service.py` | **상권 분석 Agent** — 리뷰 주제 분석(GPT), 사장님 질의응답(GPT) |
| `services/insight_service.py` | **지역 분석 Agent** — 지역 점수 0~10, 지역 보고서(GPT), 가게 리뷰 보고서(GPT), 새 평가 시 자동 분석 예약 |
| `services/review_service.py` | 방문 후 평가 저장·하루 한도, 실시간 이벤트 |
| `services/admin_service.py` | 관리 콘솔 (집계, 적재 이력, 품질 점검, 계정, 백업·2인 복구) |
| `routers/*.py` | 엔드포인트 (auth, tourist, owner, insights, admin, map, datahub) |
| `security.py`, `events.py`, `errors.py`, `db.py` | 로그인(JWT·PBKDF2), WebSocket 이벤트, 오류 형식, SQLite |

## 3. Prompt

| 위치 | 쓰는 Agent |
|---|---|
| `backend/app/prompts/review_topics.md` | 리뷰 주제별 반응 (JSON 출력 규칙) |
| `backend/app/services/course_service.py` — `_ALT_SYSTEM`, `_EDIT_SYSTEM` | 다른 코스 보기, 대화로 코스 고치기 |
| `backend/app/services/chat_service.py` — `SYSTEM_PROMPT` | 코스 대화 해석 (patch·prefs) |
| `backend/app/services/owner_service.py` — `ASK_SYSTEM_PROMPT` | 사장님 질의응답 |
| `backend/app/services/insight_service.py` — `_REGION_SYS`, `_STORE_SYS` | 지역 보고서, 가게 리뷰 보고서 |
| `backend/app/services/profile_service.py` — `_refine_desc_with_gpt` | 성향 설명 |
| `frontend/src/prompts/*.md` = `app/assets/prompts/*.md` | 웹·앱 GPT 중계 플래너 (`course_plan`, `course_chat`, `context`). 백엔드 중계 API 가 있을 때만 사용 — 현재 비활성 |

공통 규칙: 주어진 데이터만 근거로, 후보 id 밖 선택 금지, 지정한 JSON·마크다운 형식, 데이터가 적으면 적다고 말하기.

## 5. 데이터 처리 코드
자세한 흐름은 `02_데이터_활용_명세.md` 3장. 핵심 함수:
- `datahub_service.population()` — 유동인구 행 → 읍면동·지역 합계
- `datahub_service.region_crowd()` — 지역 혼잡도 지수 0~1 + 평균 대비 %
- `datahub_service.latest_date()` — 데이터가 있는 최신 날짜 자동 탐지
- `insight_service.region_scores()` — 지역 점수 (만족도 50·수요 30·쾌적함 20)
- `frontend/src/api/hub.js`, `app/lib/api/hub.dart` — D4 관광지 방문객을 장소에 매칭, 인기도 등급

## 6. 사용 모델 · 라이브러리

### 모델
| 모델 | 용도 | 설정 |
|---|---|---|
| OpenAI GPT — 개발·시연 `gpt-6-luna` | 위 8개 GPT 기능 | `backend/.env` `OPENAI_MODEL` (기본값 `gpt-4o-mini`, 계정에서 쓸 수 있는 모델로 변경) |
| 규칙 기반 대체 | GPT 없을 때 같은 기능 | 코드 내장 (정규식·키워드·템플릿) |

별도 학습한 모델은 없습니다. 점수·지표는 모두 규칙·통계 계산입니다.

### 라이브러리
`01_실행환경_및_사용자_매뉴얼.md` 2장(버전), `02_데이터_활용_명세.md` 8장(라이선스) 참고.
