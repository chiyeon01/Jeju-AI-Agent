# prompts · GPT 프롬프트

코스 플래너가 GPT 에 보내는 문장을 모아 둔 폴더입니다. 코드를 몰라도 `.md` 파일만 고치면 GPT 의 말투와 규칙을 바꿀 수 있습니다.
같은 파일이 `app/assets/prompts/` 에도 있습니다. 한쪽을 고치면 다른 쪽도 같이 고쳐 주세요.

| 파일 | 쓰는 곳 | 하는 일 |
| --- | --- | --- |
| `course_plan.md` | 처음 코스 만들기 | 성향·실시간 날씨·출발 지역·후보 장소를 보고 코스를 짭니다 |
| `course_chat.md` | 대화로 코스 고치기 | 지금 코스와 대화 기록을 보고 자유로운 요청대로 코스를 고칩니다 |
| `context.md` | 위 두 곳 공통 | GPT 에 넘기는 상황 정보(성향, 날씨, 시간, 후보 장소) 틀 |

## 규칙

- `{{이름}}` 은 코드가 채우는 값입니다 (`src/api/planner.js`). 이름을 바꾸면 코드도 같이 바꿔야 합니다.
- 맨 위 `<!-- -->` 주석은 사람용 설명이라 GPT 에 보내지 않습니다.
- GPT 는 후보 목록에 있는 장소 id 만 고를 수 있습니다. 없는 id 는 버리고, 이동 시간과 도착 시각은 코드가 계산합니다.
- 제주데이터허브 값은 숫자를 보내지 않고 등급만 보냅니다 (지역 혼잡도: 낮음/보통/높음, 관광지 인기도: 최상위/상위/보통/한산). 방문객 수 같은 숫자는 화면에만 보여 줍니다.
- 이 프롬프트는 백엔드에 GPT 중계 API(POST /tourist/ai/json)가 있고 `VITE_GPT_RELAY=true`(앱은 `GPT_RELAY`)일 때만 쓰입니다. 지금 백엔드에는 이 API 가 없어서, 처음 코스는 `/tourist/course`, 대화는 `/tourist/course/chat`(백엔드 GPT)이 맡습니다.

## 변수

| 변수 | 내용 |
| --- | --- |
| `{{context}}` | `context.md` 를 채운 결과 |
| `{{today}}`, `{{now}}` | 오늘 날짜, 지금 시각 (한국 시간) |
| `{{profile}}` | 성향 유형 이름·코드·설명·태그, 동행·이동수단 |
| `{{weather}}` | 실시간 날씨 한 줄 |
| `{{hub}}` | 혼잡도·인기도가 어느 날짜의 제주데이터허브 값인지 |
| `{{origin}}` | 출발 지역 |
| `{{start_time}}`, `{{hours}}` | 출발 시각, 이용 시간 |
| `{{candidates}}` | 후보 장소 표 |
| `{{course}}`, `{{history}}` | 지금 코스, 최근 대화 (대화 수정 때만) |
| `{{variation}}` | 같은 조건이라도 다른 코스가 나오도록 주는 무작위 힌트 |
